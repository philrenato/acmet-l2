How we know, and how to fix us. Every page lists its sources — the institution's own site, an obituary, or a Wayback capture — and says when it was last checked. Spot something wrong? Every bio has a ✎ edit this bio link (GitHub forks and opens a pull request for you), or open an issue with the correction and a source. Corrections to your own entry are authoritative — and if a living person asks to be edited or removed, that's honored, no questions.

Mirror & extend this. The whole project is open source — the database (acmet.db), the build scripts, and the recovered archive all live in one repo: github.com/philrenato/acmet-l2. Clone it, open the folder with an LLM (Claude Code or similar), and pick up where this left off — add people, verify claims, fix a record, or rescope it past metals. Start with MIRROR.md. Nobody needs permission to be in a directory; living people get a say before anything new goes public.
