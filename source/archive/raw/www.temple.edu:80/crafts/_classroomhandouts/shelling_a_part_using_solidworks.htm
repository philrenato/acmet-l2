Shelling a part Using SolidWorks

Export from Rhino:

                                    Format-STEP (STEP Schema-AP214 automotive design)

Import into Solidworks:

                                    Open

                                    Select Part

                                    Set Shell Parameters

                                    Shell - Outward

                                    Shell

                                    Save as IGES file

                                    Options -  IGES Solid/Surface - Trimmed Surfaces

                                                    Surfaces Rep - NURBS

                                                    Flatten

                                     OK

                                    Save - Selected Bodies

Import back into Rhino:

                                    Import - IGES

                                    Join all surfaces

                                    Delete extras
