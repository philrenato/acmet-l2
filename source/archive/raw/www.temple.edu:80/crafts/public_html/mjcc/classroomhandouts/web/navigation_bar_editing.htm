Navigation Bar Editing-

1. From the Tools tab, select Web Settings.

2.  The following dialog box will appear, select the Parameters tab.

3. Click on the area you wish to modify, then click on the Modify button.

NOTE:  In order for the current credits to appear on every page, each page MUST be opened and saved.  Just open the page and click on the save button.  The entire website then must be uploaded to reflect the changes.  Only the uploaded pages will reflect your changes to the navigation bar.
