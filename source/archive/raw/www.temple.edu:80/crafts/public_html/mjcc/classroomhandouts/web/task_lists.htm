Task Lists

 

Every page that has changes made and is to be uploaded must appear in the Tasks List.

Click on the Tasks icon.  A list should appear of previous pages that were uploaded.

  • To create a new Task for the list, Edit>Task>Add Task

 

 

  • The Task name should be the page that has been changed and is to be uploaded.  

        ex: file:///C:/M J C-C Site 10-09-01/public_html/mjcc/classroomhandouts/web/task_lists.htm

  • The exact name for the page is retrieved through the Page Options dialog box.  Just copy and paste the information.
  • The Assigned to option should be the current webmaster along with the month it is uploaded.  ex.:  Heather Massinger 10/01
