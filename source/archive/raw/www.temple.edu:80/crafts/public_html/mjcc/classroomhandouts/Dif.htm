M/J/C-C Junior, Senior & Graduate Portfolio Review

Guidelines
 
 
Seniors are required to hand in a complete (all metal work done at Tyler) portfolio at the completion of
Sr. Metals & Plastics 0364.  All work should be submitted on a labeled CD-ROM as TIFF files of
renderings or photo images in the sizes listed below.
 
Please prepare the following for your final review with all of the M/J/C-C Faculty on your scheduled review day.
Place your folder in the Junior, Senior, or Grad folder on System #7
 
All work completed in all M/J/C-C classes this semester.
Your portfolio in the following form for each object:
 
Each object should be placed in its own folder that contains the following files:
-.txt file(see below)
 
For CAD files:
For critiques and final reviews:
-1024 X 768.tif
-2048 X 1366.tif
-Text file (see below)
-If object is an actual, a flawless stl file for each component. (Sanders MM wax models should be sprued)
 
For your portfolio:
-4096 X 2704.tif file (for best slide output)
-2048 X 1352.tif file (for slide output)
-2048 X 1638.tif file (for 8" X 10" printout)
-4915 X 3932.tif (for 16" X 20" printout)
-1280 X 1024.tif file (for full screen display on 21" monitor for critique)
-1280 X 1024.jpg file
-1024 X 768.jpg file
-200 X 150.jpg file (for use as a thumbnail)
-800 X 600.jpg file (for Epson Digital Projector)
 
For digital camera images:
-1280 X 850.tif file (for full screen display on 21" for critique)
-2048 X 1360.tif file (for slide output)
-800 X 600.jpg (for Epson Digital Projector)
 
NOTE: Do not scale images from a smaller size to a larger size.  If at this time you only have JPEG files from
your CAD I course you may submit them.  Do not convert JPEGs to TIFF format!
 
The .txt file for each object should contain:
*it is important to turn word-wrap on in Notepad under the edit pull-down menu
 
-Object Type (Ring, Bracelet, Tea Pot, Lamp, etc.)
-"Object Title"
-Material/s
-Object State or Process (virtual, actual, tangible, raised, cast, fabricated, electroformed, etc.)
-Size
-Your Name, Class (Jr., Sr.)
-Copyright Date
 
File naming conventions:
-Place all individual object folders in a single master folder identified by your last name, first name, and year
(ex: lechtzin_stanley_2001)
-Object folders identified by your last name and object title (ex: lechtzin_ring)
-Tiffs identified by your last name, object title and size (ex: lechtzin_ring_1024_768.tif)
-Text files identified by your last name and object title (ex: lechtzin_ring.txt)
 

Note: all file names to be in lower case letters with no spaces allowed between words

(use an underscore)
