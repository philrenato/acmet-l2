* Virtual        ---      An object that can not be made physical (for one reason or another)                                            and exists only in digital form.
 

* Actual         ---       An object that has been created in digital form, which contains all necesary data                                             and information for output, but has not yet been made. 

 

* Tangible    ---     An object that has been made and physically exists.

 

* Actual objects were designed to be made tangible through the application of RPT or CNC machining     processes.
